# Huffman Algorithm

A Python project for exploring lossless file compression through Huffman coding. It uses binary trees to represent variable-length codes, assigning shorter codes to frequently occurring symbols.
Features
- Models Huffman coding trees.
- Provides compression and decompression routines.
- Includes utilities for manipulating bits and bytes.
- Contains tests for tree and compression functionality.
- Includes representative text, image, and audio files for experimentation.

## Requirements

Python 3.10 or later.

Representative sample inputs are included in `files/`. Large media inputs and generated compressed outputs are omitted.

## Validation

Python source files pass syntax checks. Runtime behavior and the included tests have not yet been verified for this version.
